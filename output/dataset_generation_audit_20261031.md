`289d8541c4952592b93737c71010b02a434e7424bc53aad65259d2e22957000e`。

结论：生成器存在声源几何、混响参数、划分与断点恢复问题。但已检查数据没有显示采样率、参考通道、长度或整体 SNR 错误，不能据此认定生成器是 PESQ 未达 3.4 的主要原因。

## 已核验通过的链路

统计了训练 53600 条、原始验证 2680 条、比较 600 条的全部 metadata；实际读取比较集全部 600 对 WAV，以及训练集固定随机抽样加 SNR/RT60 分层补样共 560 对 WAV。

| 检查 | 比较集 600 条 | 训练抽样 560 条 |
|---|---:|---:|
| 非 16 kHz、mixture/target 长度不等或不是 96000 点 | 0 | 0 |
| 通道配置 | 全部 9 通道 mixture、单通道 target | 同左 |
| 非有限值、target RMS 小于 1e-6 | 0 | 0 |
| mixture 第 0 通道与 target 在 ±320 点内互相关峰值不在零延迟 | 0 | 0 |
| 实测 SNR 与 metadata 最大绝对误差 | 3.14e-8 dB | 1.64e-5 dB |
| WAV 保存格式 | 全部 FLOAT | 全部 FLOAT |

互相关检查可排查明显整体错位，不能证明每个时频点的标签都正确。训练 WAV 只做抽样检查，不代表全部 53600 对已逐点核验。

当前训练和评估均取 mixture 前 8 通道、原始顺序，以第 0 通道作为目标参考；与生成器保存的 target 第 0 通道一致。生成器输出 9 通道本身不构成当前接口错误。

合成 chirp + 噪声运行原始 `generate_one_sample`，再独立重建相同房间 RIR 做卷积：9 通道 target 最大误差 `7.45e-9`，实测 SNR `-2.0000000075 dB`。未发现目标单独归一化或模拟导致的额外整体时移。

FLOAT WAV 允许幅值超出 ±1；比较集 170 条、训练抽样 299 条峰值超过 1，不能将它们直接当成保存时削波。不要为降低数值幅度而只归一化 mixture 或只归一化 target。

## 混响重建的证据边界

使用当前 `max_order=10` 及 metadata 中毫米精度的房间/源坐标，重建了 7 个代表性 RIR。例如请求 RT60 约 0.700 秒的一例，当前配置得到的 RIR 总长度仅约 0.143 秒，库按 60 dB 衰减测得约 0.122 秒；请求 0.500 秒的一例，RIR 长度约 0.214 秒，测得约 0.171 秒。

这些是当前实现的代表性重建结果。历史原始 RIR 未保存，不能把它们表述成对全部既有训练样本 RIR 的直接测量；短混响、直达声占主导时，20 dB 外推也可能不稳定，不能只凭该数值判定所有 RT60。

## 对当前 PESQ 差距的判断

使用原 epoch 17、完整 600 条评估记录做描述性分组，未修改任何音频、分数或评估协议：

- 全部 600 条平均 PESQ：2.5366868689。
- 目标/噪声位置重合的 2 条：平均 1.0543515682。
- 其余 598 条：平均 2.5416445120，只比完整集合高约 0.00496。
- 目标角度误差不超过 1° 的 439 条：平均 2.5639180640。
- 目标角度误差超过 1° 的 161 条：平均 2.4624353492。

这些分组还混有 SNR、源内容等差异，不能解释为单因素因果效应。位置重合会伤害相应样本，但这两条不足以解释整体从约 2.54 到 3.4 的差距。若所有对照使用相同训练和比较数据，生成器共有的问题也不能自动解释模型之间的差距。
