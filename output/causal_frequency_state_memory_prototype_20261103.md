# 独立全频率状态记忆原型：尚无真实质量或目标设备速度证据

目标仍为原固定600条完整语音的16kHz WB-PESQ至少3.4、整个部署链路因果且逐流状态有界独立、每个实测hop低于10ms，以及双4070完整53600/600/600、global8和6700次有限更新的整轮不超过3600秒。当前实际模型仍为schema27，第2轮3.0774879499；本原型没有注册、接入训练或替换活动任务。

## 需要核实的结构问题

交付是准备一个直接学习语音/空间结构的独立增强网络，作为当前完整训练趋势不足时的待测方案；不把其他数据集上的论文分数当作本项目预期成绩。两个问题是：能否用固定状态进行全频率/因果时间交互，以及能否在实际4070上满足速度和完整训练预算。

Light Search读取了作者实现及一手论文。TF-SkiMNet的[作者代码](https://github.com/zx1292982431/TF-SkiMNet/blob/main/TF-SkiMNet.py)在频率轴运行双向LSTM，将每个时间帧作为独立批次；频率汇总的隐藏态/细胞态经过单向时间LSTM，再传入下一块。双向处理发生在同一帧内，不意味着使用未来时间帧。发布代码提供整段forward，逐流状态接口仍需独立实现和验证。

[DeFT-AN RT论文](https://www.isca-archive.org/interspeech_2023/lee23j_interspeech.pdf)的§2.2使用覆盖当前及全部过去帧的时间注意力，§3.1另用32ms矩形分析窗和16ms合成窗。照搬它不能直接满足本项目的固定缓存及原始前端要求，因此没有因其名称含real-time而接入。SpatialNet路线在项目既有schema22中已经验证过，没有重新作为新方法启动。

## 本项目独立改型

`experiments/causal_frequency_state_memory.py`是独立实现、尚未注册的原型，不声称作者确认或完整复刻。默认6块、宽度32，共498306个可训练参数，没有冻结源模型、外部教师或旧网络叠加。

- 输入仍为原512/160/320/power0.5前端的8麦压缩RI。模型内部按当前帧参考幅度构造16个RI特征，并显式增加当前增益的对数，使过去帧能量仍可进入时间记忆；外部波形归一化不变。
- 每块进行同帧局部频率卷积、同帧双向频率LSTM及局部因果时间卷积。除最后一块外，频率LSTM的双向隐藏/细胞汇总分别进入单向时间LSTM，以其当前及过去信息初始化下一块的频率建模。
- 编码、局部时间卷积、解码都有独立左侧历史；时间LSTM保存独立隐藏/细胞态。调用方持有全部状态，输出状态复制分配且不修改输入状态。单流FP32模型缓存996112字节，不随已接收时长增长；这不包含20ms前端缓冲或音频驱动。
- 读出从零开始，初始输出是参考0的压缩复谱；这是冷启动独立模型，未继承当前3.05模型的输出或权重。不能把初始参考输出当作已有增强能力。

这保留了状态记忆方法，同时改变了输入通道、压缩谱/增益特征、残差读出及流式接口，所以不把结果当作TF-SkiMNet论文复现。原型源码SHA256为`08d48f400ec6db7b59e4b9bdb3a737a08ddfdae98ab4b5c188a70ae845e2abc3`。

## 实际检查及边界

`tests/test_light_frequency_state_memory.py`共8项不同CPU检查：7项在10.69秒通过；新增完整6秒波形一项在16.01秒通过，其余7项在该次选择中未运行。输入全部为合成数据。

- 1/9/33帧的零读出逐点保持参考；从自然零读出开始的两次有限Adam更新实际改变编码、频率LSTM及隐藏/细胞时间记忆参数。
- 非零读出的未来输入梯度严格为0；未来扰动检查在相同no-grad执行模式下比较。初版测试错误地对比grad-enabled与no-grad两个CPU执行模式，现已修正测试方式，没有放宽误差阈值。
- 不同分块输出一致，状态大小固定996112字节，旧状态不被写入，不同流的新状态不共享数据指针；错误批大小及缺失时间记忆被拒绝。模型对过去帧增益的梯度非零，只证明信息通路存在，不证明质量收益。
- 两次更新后的模型处理完整96000点/6秒/8通道波形，保持原STFT/重建参数；整段输出与600个160点输入hop的流式输出长度均为96000，最大绝对误差通过1e-5检查，暖机状态丢弃。

上述16.01秒是包含初始化、两次训练更新、整段计算和600hop流式计算的CPU测试总时间，不是RTF，也不能证明任何目标设备实时性。没有读取真实语音、使用GPU、下载作者权重或安装依赖。公共候选仍为原31个，运行中的schema27源码没有变化。

实际4070的整段/流式数值一致性、所有hop的10ms截止时间、真实6秒双卡内存和吞吐、完整53600/600/600轮次及PESQ均未验证。在合适的完整轮次边界保留现有权重/优化器之后，才能安排独立真实预检；不因CPU功能检查通过而切换正式训练。

后续第5轮评估窗口已完成该原型的实际FP32延迟筛查：在原GPU0评估期间，仅使用确认空闲的GPU1 RTX4070，对真实完整6秒输入测600个160点hop，平均2.52832692ms、p99为2.77732947ms、最大2.96316505ms，10ms超时0次，峰值分配30400000字节；暖机状态丢弃。使用随机非零读出、0次训练更新，不计算PESQ，原训练没有暂停。记录为`frequency_state_memory_gpu_screen_epoch5_20261103/frequency/latency.json`。它仍未注册、没有真实训练质量或整轮预算证据；公共第32个候选是另一个已完成双卡预检的独立全频模型，不能把其成绩归于本原型。
