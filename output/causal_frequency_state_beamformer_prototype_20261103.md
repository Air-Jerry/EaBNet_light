# 频率状态记忆与物理复数滤波：未注册的独立原型

当前完整600条最佳仍为schema27第5轮3.0893360313，目标3.4尚未达到。全频GRU物理滤波schema29第5轮为1.69100370，继续第6轮；本原型完成32/128次真实更新筛查后未显示支持优先切换的证据，没有注册或替换活动任务，也不将小样本拟合当作泛化。

当前全频GRU通过单个压缩后的全频序列保存时间信息。本候选复用此前已验证的频率状态记忆骨架，增加同帧空间特征和物理8麦滤波输出，尝试更强的频谱与局部时间归纳偏置。这是独立实验，不是作者代码或论文完整复现；不能仅凭结构推断一定优于现有模型。

`experiments/causal_frequency_state_beamformer.py`包含504080个可训练参数，没有教师、冻结主干或外部权重。原始16kHz/FFT512/hop160/周期Hann320/power0.5、前8麦原顺序及参考0保持。39维输入为16个归一化RI、14个IPD实/虚分量、7个幅度比、参考包络和当前对数幅度；外部波形不做额外归一化。

6个宽度32块进行同帧局部频率卷积、同帧双向频率LSTM和左侧4帧局部时间卷积。频率LSTM的隐藏/细胞汇总经单向时间LSTM后初始化下一块的当前频率序列，只使用当前和过去。时间方向没有双向计算或随时长增长的缓存。模型流状态FP32单流1086576字节，包含所有卷积历史和时间隐藏/细胞态，不含前端及音频驱动。

解码器输出8麦复数系数，先以`Y_m=I_m|I_m|`还原物理谱，再计算`sum(conj(w_m + delta_m0)Y_m)`，最后用稳定的压缩残差保留原参考：`I0+C(enhanced)-C(Y0)`。单位参考系数先加到权重，可避免先减去再加回参考物理谱时的浮点抵消。CPU解析相位切换测试曾出现1个谱点误差1.60e-7，修正运算顺序后通过原1e-7绝对容差，没有放宽阈值。所有操作均在模型内部当前帧进行，不用参考语音或非因果后处理。

新增训练专用`experiments/fp16_lstm_training.py`，沿用已有GRU精度上下文的方式，仅在CUDA训练时对LSTM使用FP16 autocast，参数和调用方隐藏/细胞态保持FP32；CPU及推理走原FP32路径，并保证异常退出后恢复原forward。卷积仍为FP32。该精度策略已完成下面的真实32/128步单卡训练筛查，但尚未完成正式入口和双卡整轮预算验证。

8项CPU检查在28.73秒通过：全零/极小/普通输入的零读出精确保留参考、物理增益及复相位/麦克风切换的解析结果、从自然零读出开始的两次有限Adam实际更新编码/频率/隐藏与细胞记忆、未来梯度为0和扰动独立、分块一致及不可变独立固定状态、实际更新后完整96000点原前端与600hop波形误差小于1e-5，以及LSTM精度上下文CPU路径和异常恢复。该总耗时不是RTF，合成CPU测试不代表真实语音质量或设备实时率。
